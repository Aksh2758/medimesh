🏥 Building MediMesh — AI triage for rural India, powered by AMD

India has ~30,000 Primary Health Centres serving 800 million people.
Most of them run without a doctor on site.

A nurse alone has 60 seconds to decide:
→ Send this child home?
→ Or emergency referral to district hospital?

A wrong call can cost a life.

I'm building MediMesh — a 3-agent AI system that gives that nurse a second opinion in under 60 seconds.

Here's how it works:

🔴 Agent 1: Triager
Reads symptoms + vitals, flags danger signs, assigns GREEN / YELLOW / RED severity using WHO IMCI guidelines.

🔬 Agent 2: DDx Reasoner
Generates top 3 differential diagnoses ranked by probability, grounded in evidence.

💊 Agent 3: Drug Safety Auditor
Checks current meds against proposed treatment for dangerous interactions — flags them before harm happens.

All three agents are orchestrated by CrewAI, running on Llama 3.1 8B via AMD Developer Cloud (ROCm + vLLM).

The knowledge base: WHO IMCI guidelines + an Indian drug interaction database — all local, all pre-indexed in ChromaDB.

What I've shipped so far:
✅ AMD Developer Cloud instance live
✅ All 3 agent system prompts written
✅ ChromaDB RAG populated with 25 IMCI chunks + 30 drug interaction pairs
✅ CrewAI orchestrator wired end-to-end
✅ Streamlit UI running (Hindi + English labels)

Building this for the AMD Developer Hackathon on @lablab.ai

More updates coming. Follow along if you're interested in healthcare AI, multi-agent systems, or just want to see how fast you can build something meaningful. 🙏
